# wgkeeper brand

The logo is the name: **wg** in bold red, **keeper** in regular grey, set in [Geist](https://vercel.com/font). Products add their name: **wgkeeper node**, **wgkeeper console**. The colours read on both light and dark backgrounds, so there is one file per logo.

| File | Use |
| --- | --- |
| `wgkeeper.svg` | Umbrella repo, docs site |
| `wgkeeper-node.svg` | Node README |
| `wgkeeper-console.svg` | Console README |
| `icon.svg` | Favicon, small square spots |
| `avatar.png` | GitHub organisation avatar (512 × 512) |

In a README:

```html
<p align="center">
  <img alt="wgkeeper node" src="https://raw.githubusercontent.com/wgkeeper/wgkeeper/main/brand/wgkeeper-node.svg" height="64">
</p>
```

Other repositories link to these files, so don't rename them.

## Colours

- Red `#EB2F35` for `wg`
- Grey `#7A7A7A` for `keeper` and the product name
- Icon tile `#171717`

## Writing the name

Always lowercase: **wgkeeper**, **wgkeeper node**, **wgkeeper console**, also at the start of a sentence.
